Organized as a flat package of domain-scoped sub-packages (`host`, `link`, `path`, `mesh`, `flow`, `traffic`), each exposing an orchestrator function that returns `list[DiagnosticResult]`. Host-level probes (connectivity, DNS, gateway, interfaces, routing, TCP/UDP, latency, packet loss, resource usage) are aggregated in `host/collector.py`; link-layer metrics (utilization, errors, congestion) are computed from `psutil` counters in `link/collector.py`; path analysis wraps traceroute and hop probing in `path/collector.py`; `mesh/runner.py` loads JSON topologies and fans out ICMP pings to many targets; `flow/analysis.py` ingests sFlow records via `ingest.sflow` and ranks elephant flows; `traffic/speed.py` measures download goodput over HTTP and jitter via ping. All collectors depend on shared primitives under `core.result` (`DiagnosticResult`, `DiagnosticStatus`, `Severity`) and `core.metrics.*` for bandwidth/congestion/jitter calculations, keeping this module free of I/O formatting except optional `run_*` helpers that print Rich tables. Dependency direction is one-way: diagnostics → core.metrics / core.result / ingest.sflow / storage.baselines, with no cross-imports between sibling sub-packages.

The root package exposes a Typer CLI (`cli.py`) that dispatches subcommands under `host`, `link`, `path`, `traffic`, `flow`, `mesh`, and `diagnose` to functions in the `diagnostics.*` and `collectors.*` packages; collected observations are typed via Pydantic models in `core.result` and `core.engine`, then fed into the `analysis.engine.RuleEngine` for cross-layer root-cause synthesis. The `pyproject.toml` declares the `netforge` console script and discovers all sibling packages (`core*`, `diagnostics*`, `analysis*`, `ingest*`, `collectors*`, `storage*`) as one distribution, while the optional `agent` and `controller` subpackages provide standalone HTTP services (health/inventory probes and job fan-out) that communicate over the same core observation model. Tests in `tests/` exercise the full stack end-to-end against these shared contracts.

Flat package of three protocol-specific ingest modules sharing a common MVP pattern: each module exposes a `load_*_records` / `poll_*` function for offline data consumption and a `start_*_collector` entry point that currently raises `NotImplementedError`, deferring live UDP/SNMP collection to later phases. The `ipfix.py` module reuses the sFlow JSON schema via `ingest.sflow.load_sflow_records`, treating IPFIX/NetFlow records as identical flow dicts with keys `src`, `dst`, `bytes`, `packets`, `proto`. The `__init__.py` only documents the package purpose; there is no central dispatcher — callers import the desired protocol module directly. Dependency direction is one-way: `ipfix` depends on `sflow`; `snmp_counters` is independent.
